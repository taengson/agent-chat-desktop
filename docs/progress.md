## 현재 상태

Wails 3 기반 데스크톱 앱과 심플한 채팅 UI를 구성했습니다. OpenAI 호환 모델 조회, SSE 스트리밍 채팅, 오류 처리 및 생성 중단을 구현했으며 모의 HTTP 응답 기반 테스트와 macOS 앱 패키징을 통과했습니다. 실제 로컬 LLM 서버에서 모델 조회, 스트리밍 대화 및 긴 대화 스크롤이 정상 동작하는 것을 확인했습니다. AI 응답은 GFM Markdown으로 읽기 좋게 표시하며, 현재 선택한 모델의 누적 토큰 사용량과 응답별 성능 정보를 확인할 수 있습니다.

첫 번째 목표인 로컬 LLM 기본 채팅은 완료했습니다. 대화는 사용자 설정 폴더의 Markdown 파일로 저장하며, 앱 시작 시 목록에서 선택하거나 새 대화를 시작할 수 있습니다. 텍스트·코드·텍스트 기반 PDF·`.docx`·`.xlsx`는 원본을 복사하지 않고 추출한 텍스트만 문맥으로 사용할 수 있습니다. 큰 문서는 제목·시트·문단 단위로 나누고 질문 관련성과 앞뒤 문맥을 기준으로 골라 전달하며, 관련 단위를 찾지 못하면 앞·뒤 발췌본을 사용합니다. 스캔 PDF OCR과 `.doc`, `.xls`, `.ppt`, `.pptx`는 지원하지 않습니다. 서버 URL은 마지막 사용 주소와 이름 있는 연결 프로필로 저장·전환할 수 있지만, 모델과 API 키는 저장하지 않고 매번 모델 조회와 API 키 입력을 거칩니다.

벤치마크 동기화는 새 v2를 구현 중입니다. 이전 v1 LAN 동기화는 태그 `benchmark-sync-v1`에 보관하고 `main`의 코드·화면·실행 경로에서는 제거했습니다. 현재는 ANP Go SDK 기반 장치 신원, 결과 proof, 앱 내 직접 TLS 1.3 수신 endpoint, 서명된 초대·양쪽 fingerprint 승인 페어링, 로컬 보안 활동 기록까지 완료했으며, E2EE 전송이 다음 단계입니다. 아래 2026-09-14 항목은 v1을 개발했을 당시의 이력입니다.

### 2026-09-14

- 왼쪽 작업 공간을 세로 메뉴로 정리하고 **결과 동기화** 화면을 추가했습니다. 같은 네트워크의 PC 주소와 일회용 코드로 연결 요청을 보낸 뒤 상대 PC가 승인해야 신뢰한 PC로 저장됩니다.
- 연결한 PC마다 완료된 벤치마크 기록을 **동기화**로 직접 실행할 수 있게 했습니다. 동기화는 먼저 받고 이어서 보내며, API 키, 연결 인증 정보, 대화, 동기화 기록은 전송하지 않습니다.
- 벤치마크 기록에 `내 PC`·`보고서`·`동기화` 출처와 원본 장치 정보를 저장했습니다. 같은 결과는 `내 PC > 보고서 > 동기화` 순서로 유지하며, 동기화 원본이 같지만 내용이 달라진 경우에는 덮어쓰지 않고 충돌로 남깁니다. 외부 기록을 삭제하면 다음 동기화에서 다시 가져오지 않습니다.
- 모델 실험실 사이드바에 접고 펼칠 수 있는 **동기화된 벤치마크** 목록을 추가했습니다. 동기화 활동은 이 PC에만 최근 200건을 남기고 사용자가 지울 수 있습니다.
- 결과 동기화 작업 공간의 왼쪽 사이드바에는 승인 대기 중인 연결 요청과 승인·거절 동작을 표시하고, 연결된 PC별 주소와 최근 동기화 성공·실패 상태를 요약하도록 했습니다.
- 수신 요청은 **결과 동기화** 메뉴의 건수 배지와 다른 작업 화면의 안내 상자로 알리고, 동기화 화면에서는 가장 위의 강조 카드에서 처리하도록 보완했습니다. 승인·거절한 요청은 목록과 알림에서 즉시 사라집니다.
- 동기화 작업 화면의 새로 고침과 발신 요청 상태 목록은 실제 동기화를 실행하지 않거나 연결 완료 후에도 남아 혼동을 주므로 제거했습니다. 발신 PC의 승인 상태 확인은 화면에 표시하지 않고 계속 수행합니다.
- 앱을 다시 열면 결과 동기화 화면의 PC 이름·주소·코드·연결한 PC·대기 요청·활동 기록과 인증 권한을 초기화합니다. 같은 PC를 식별하는 장치 ID, 이미 동기화한 결과와 외부 결과 제외 목록은 유지하며, 다시 동기화할 때는 새 일회용 코드로 연결합니다.
- 동기화 방향을 고르는 버튼은 제거하고 **동기화** 하나만 남겼습니다. 이 동작은 상대 결과를 먼저 받고 이어서 이 PC 결과를 보내므로, 같은 개인 PC 사이에서 가장 직관적인 기본 흐름입니다.
